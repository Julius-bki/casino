# Zur Goldenen Elster

Ein Spielgeld-Casino in einer einzigen HTML-Datei: 31 Spiele, darunter 16 Automaten, Texas Hold’em gegen drei Computergegner, Roulette, Blackjack und Beutekisten.

Dazu ein Levelsystem: Jede Runde bringt Erfahrung, jedes Level bringt Token. Für Token gibt es Ausrüstung, die das Glück leicht hebt (höchstens +5 %), und 28 Erfolge bringen weitere Token.

Es gibt nur Spielgeld (Taler). Nichts davon ist echtes Geld, und man kann nichts kaufen oder auszahlen. Der Spielstand liegt im Browser (localStorage).
